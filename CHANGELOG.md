## [0.0.2]

### Changed

- NISAR collections now use the COG output driver instead of GeoTiff.
- Dataset strings are now more loosely validated by checking only if they are present in the list of valid input strings provided by GDAL.

## [0.0.1]

### Added

- Add a Harmony service for performing variable extraction, spatial subsetting, and reprojection on NISAR products.
